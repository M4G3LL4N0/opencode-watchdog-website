# Contributing to Opencode Watchdog Website

## Setup

```bash
gh repo clone M4G3LL4N0/opencode-watchdog-website
cd opencode-watchdog-website
```

Install dependencies using the manifest present in the tree
(package.json).

## Before opening a pull request

- Run the existing test suite.
- Keep unrelated reformatting out of the diff.
- Describe what changed and why, and what you verified.

## Commit messages

Conventional commits: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`.
